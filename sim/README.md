# sim

The simulator engine, terminal client and HTTP server. See the [root README](../README.md) for features, build and run instructions, and [docs/API.md](docs/API.md) for the web API.

Targets: `dnd_core` (library), `dnd_sim` (terminal), `dnd_server` (HTTP), `dnd_tests` (also registered with CTest, together with `api_smoke`).
