# Docs

- [API.md](API.md): the HTTP/JSON reference for `dnd_server`. Covers content and LLM status, creating, saving and loading games, exploration commands, combat (`advance`, `action`, `role`), the plain-English `say` endpoint, and the bundled web client. Start here if you are writing your own front end.

The original design notes for the project are [dungeons_dragons_c_simulator_architecture.md](../../dungeons_dragons_c_simulator_architecture.md) in the repository root. They describe the first sketch; the code has since grown (modules, save and load, remote control, LLM support), so treat the READMEs and `API.md` as current.
